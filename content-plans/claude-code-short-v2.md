**與 v1 差異**:修正了 v1 對競品的錯誤宣稱,改用 2026 年站得住的真差異;口播改成口語化。

## 一、為什麼要改 v1(事實核查)

| v1 的講法 | 2026 現況 | 判定 |
|---|---|---|
| 「Cursor/Copilot 只是建議者,Claude Code 才是執行者」 | Cursor 2026/1 已出 CLI + agent + Background Agents(雲端自主跑);Copilot 也有 agent | ❌ 過時,會被留言打臉 |
| 自然語言→自動讀 codebase→改→跑測試→commit | 屬實 | ✅ |
| 200K context | 屬實,且 Cursor 號稱 200K 實測常被截到 70–120K → 這才是真差異 | ✅ 可主打 |

**新切角**:不喊假二分法,改用兩個無法反駁的真點 ——
1. 這支影片的腳本本身就是 Claude Code 在背景跑出來的(meta 證據)
2. 真差異 = 不用顧、能在背景自己跑 + 整包程式真的讀得進去

```

[5-18s] 先接住觀眾想吐槽的點

    所以重點早就不是『誰會做事』——」

[18-50s] 真正的差別
🎬 錄屏:不開任何視窗,純終端打一句話
🎙️「——重點是,它做事的時候,你還要不要在旁邊顧。
    Claude Code 厲害在:不用開視窗、不用盯著看。
    你給它一句話:『把這專案的程式全補上型別、跑測試,壞的自己修』,
    然後你就去忙別的,它甚至能排程半夜自己跑。
    而且它是把你『整包』程式讀進去再動手,
    不會讀到一半就忘了前面——這點很多工具嘴上有,實際用就縮水。」

[50-68s] 誠實講缺點(這段反而加分)
🎙️「當然它不是萬能。
    它只能用 Claude 這顆腦袋,不像 Cursor 可以換不同 AI;
    你也沒辦法一行一行盯著它改。
    所以你喜歡『看著 AI、每步自己確認』→ Cursor 比較適合你;
    你想『丟給它、它自己做完』→ 那 Claude Code 就是為你做的。」

[68-85s] CTA(用本片當證據)
🎬 終端機 claude 啟動 + CTA 字卡「連結在下方 ↓」
🎙️「不信?這支影片就是證據——
    腳本、分鏡、連社群貼文,它一次在背景全部生完。
    下面有試用連結,裝起來隨便丟個任務給它,
    然後回來留言跟我說:你第一個叫它做什麼、它有沒有凸槌。」
```

**字卡強調點**
- `0:02`:「腳本不是我寫的」
- `0:30`:「你就去忙別的」
- `0:42`:「整包讀進去,不會讀到一半就忘」
- `1:05`:「丟給它 → 它自己做完」
